## 一、G1 · 需求方向（要你判断"这个癌种该做什么"）

### 1.1 这个癌种和家族其它工作台不一样在哪

| 维度 | AML 的特殊性 | 落成了什么 |
| --- | --- | --- |
| **时间压力** | 从确诊到开始诱导化疗以**天**计，不是以周计。患者和家属在还没弄懂病名时就已进入治疗 | 诱导日历按**天**（D1–D42），不是按疗程聚合 |
| **7+3 的天结构** | 「为什么第 8 天反而最危险」——化疗打完才是谷值期开始 | dayGrid 里谷值带紧接停化疗日、骨穿窗口按「停化疗后 7–14 天」推算 |
| **粒缺发热的小时精度** | 半夜烧到 38.5 该怎么办，是按小时决策的事 | hourLane 独立轨道：体温到小时 + 38.3/38.0 两条定义参考线 + 血培养/抗生素节点 |
| **双主体（照护者代记）** | 粒缺血象期患者常在隔离/乏力状态，体温与用药常由照护者代记 | author_role 贯穿所有记录，界面上标"谁记的" |
| **MRD 双口径** | 流式与 PCR（靶点绑定）不可换算；FLT3-ITD 的 PCR 灵敏度不足 | 两列并列、跨方法不连线、无单一"MRD 状态"字段 |
| **移植是状态不是事件** | 评估、供者、Day+N、GVHD 观察是一条长线 | Day+N 相对天数轴（Day 0/14/100），移植页零推荐 |
| **私密（对死亡的准备）** | 这类内容患者只想留给自己和医生 | 私密三出口：默认不进导出/看板摘要/AI 上下文 |

### 1.2 十条一级线 / 27 个页签

看板 · 诊断与基因(3) · 诱导与疗程(4) · 粒缺血象与支持(5) · MRD 与随访(3) · 移植(3) · 病情一图秀 · 营养与生活(2) · 心理与家庭(3) · 资料与复诊(4)

与家族其它癌种的重名率 **20%**（2/10，仅"诊断与基因""资料与复诊"名称相近，内容按 AML 重写）。详见 `docs/DIFF-MATRIX.md`。

### 1.3 三个新组件（本癌种首创，可被后续癌种复用）

1. **dayGrid**（按天网格）——适用于任何"给药日程按天排、且每天状态不同"的治疗
2. **hourLane**（小时级时间轴）——适用于任何"以小时为决策单位"的急症（发热、低血糖、出血）
3. **Day+N 轴**（相对天数锚点）——适用于任何"以某个事件为 0 点"的长期随访（移植、CAR-T、放疗开始日）

### 2.4 本轮独立评审发现的 3 个 P0（已修，详见 `docs/M2-REVIEW-2026-10-26.md`）

1. **骨穿复核窗口标错一周**：带标 D21–D28，标签写「停化疗后 7–14 天」（应为 D15–D22），而 D15 真有骨穿记录。
2. **粒缺发热判定丢掉时长条件**：`v>=38.3||v>=38.0` 等价于 `v>=38.0`，单次 38.1℃ 也弹急症。
3. **体温重复入列**：同一条体温进轨道两遍，双主体计数翻倍。

这三条的共同点：**探针全绿但语义错**。已各补一条会报红的常驻断言（都做过变异测试）。

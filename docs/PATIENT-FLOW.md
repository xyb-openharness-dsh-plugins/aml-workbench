# 患者流程（PATIENT-FLOW）· 三流骨架（M1 填实）

流一：急症入院与诱导（确诊）——乏力淤青→血象异常→确诊 AML→入院开始 7+3；粒缺期发热急症 → 化疗日历（按天）+ 粒缺发热轨道 + 输注记录。产物：诱导期记录。
流二：MRD 监测与缓解后治疗——每疗程后骨穿；"MRD 转阴了是不是就好了"；高危→移植评估 → MRD 趋势（双口径）+ 移植评估档案（供者类型记录）。产物：MRD 趋势 + 移植评估记录。
流三：缓解后长期随访（家属代记）——复查血象、感染预防、疫苗、"还能正常上班吗" → 长期随访视图 + 感染档案 + 私密（对死亡的准备）三出口。产物：复诊摘要。
反推原则同家族；与 cervical/THY 重名率 ≤70% 实测。
